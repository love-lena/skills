# Plain HTML Artifacts

Read [HTML Artifacts](../html-artifacts/SKILL.md), then [Plain](../html-artifacts/references/plain.md). Follow that route unless the user's explicit styling request overrides it. For picture-led teaching, also use the canonical Visual Explainer guide.

The canonical skill owns all guidance and resources. The legacy `assets/`, `scripts/`, and `references/` paths are compatibility links to it.

This entrypoint requires `html-artifacts` installed alongside it. If it is missing, install both from `love-lena/skills`; see the repository installation instructions.
