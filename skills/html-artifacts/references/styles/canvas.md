# Full-canvas map · work in the center

The object is the organizing unit. Relationships, annotations, and actions live where they apply in its space.

## Composition

Give the object the dominant surface. Use containment, proximity, layers, and direction only where those spatial relationships carry meaning. Labels identify the object in place; a separate presentation headline or dashboard shell may be unnecessary. Provide a contextual inspector only when selecting and working with objects warrants one.

The approved square example (1280 × 1280) uses circular regions to convey its particular system. Circles are not the style. A design canvas, geographic field, chart, or component view can use the same approach. Preserve legibility through reflow, local scrolling, or purposeful navigation.

## Visual language

Graphite `#171C22`, light ink `#E7ECEF`, mint `#8FE3C1`, quiet surface `#2A413D`. Use readable sans-serif labels, fine connectors, restrained boundaries, and shallow or absent shadows. Spatial grouping carries hierarchy; accent marks meaningful relations and active objects.

## Apply it

- **KPIs:** the chart is the primary object; values and explanations label relevant marks rather than living in separate summary tiles.
- **Design feedback:** comments pin to the part under discussion; selections connect to details in a contextual inspector.
- **Fast forms:** edit a selected object's properties beside it when seeing the object improves the input decision.
- **Explainers:** show boundaries, neighborhoods, ownership, or relationships directly, with uncertainty attached to the affected path or region.

Choose this when the object has meaningful spatial structure. A flat inventory often reads better as a register. A large empty canvas alone is not a composition, and distance or area must not invent quantitative meaning.
