# Fancy HTML Artifacts

Read [HTML Artifacts](../html-artifacts/SKILL.md), then [Fancy](../html-artifacts/references/fancy.md). Choose one appropriate composition and read its guide and approved visual example. Produce multiple alternatives when the user requests them.

For picture-led teaching, also use the canonical Visual Explainer guide. Explicit user references and choices take precedence. The canonical skill owns all guidance and examples.

This entrypoint requires `html-artifacts` installed alongside it. If it is missing, install both from `love-lena/skills`; see the repository installation instructions.
